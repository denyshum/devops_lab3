# Лабораторна робота №3: Основи роботи з Git

## Опис проєкту
Цей репозиторій створено для вивчення системи контролю версій Git та платформи GitHub. Основна мета — відпрацювати навички створення комітів, керування гілками, вирішення конфліктів злиття та базової автоматизації через GitHub Actions.

## Використані інструменти
* **Git** — локальне керування версіями.
* **GitHub** — хостинг коду та Pull Requests.
* **Markdown** — мова розмітки для документації.

## Основні команди

| Команда | Призначення |
| :--- | :--- |
| `git clone` | Завантаження репозиторію на локальний ПК |
| `git checkout -b` | Створення та перехід на нову гілку |
| `git merge` | Злиття гілок |
| `git push` | Відправка локальних змін на сервер |
